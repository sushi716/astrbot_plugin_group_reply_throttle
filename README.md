# astrbot_plugin_group_reply_throttle

群聊**回复节流**：同一个群在 N 秒内只保留一条主动回复，把"一条消息触发了好几条回复"这种撞车现象压掉。

## 典型场景

装了多个会自动说话的插件（主动搭话 / 关键词回复 / @必回 / 表情包挂载）时，一条群消息可能同时命中多个触发器，
结果短时间内连发好几条。这个插件在发送阶段做最后一道闸：**同一群 N 秒内只放行一条**。

被真正 @ 的回复默认**不受节流影响**（保证"叫她就一定应"）。

## 安装

```bash
cd <AstrBot>/data/plugins
git clone https://github.com/sushi716/astrbot_plugin_group_reply_throttle
```

## 配置项

| 字段 | 默认 | 说明 |
|---|---|---|
| `throttle_seconds` | 15 | 节流窗口（秒） |
| `stamp_file` | 空 | 共享时间戳文件；留空则用插件目录下的 `group_last_send.json` |
| `ignore_at` | true | 被 @ 时不节流 |

> 如果你有多个插件都需要读取"上次发言时间"，让它们读写**同一个** `stamp_file` 即可实现跨插件协同。

## 兼容性

AstrBot v4.x（实测 v4.27.2）。

## 已知限制

- 节流是"丢弃"而非"排队"：窗口内的第二条会直接被丢掉，**不会延后发送**
- 时间戳文件是本地文件，多进程部署时请指向共享路径
